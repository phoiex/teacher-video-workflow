# 使用

打开 Dify 发布后的应用，先描述主题、学生基础和目标时长。已有讲稿可以直接粘贴，也可以上传 PDF、PPTX，再选择要讲的知识点。

一条简短要求即可起步：

> 做一节面向高中生的注意力机制微课，约 4 分钟。学生没有线性代数基础，用一个贯穿全课的例子解释权重和信息汇总。普通话配音，简体字幕，ASCII 终端科技风格，先让我看分镜。

随后按页面提示操作：

1. **确认课程要求。** 已填写的信息会带入确认表，补齐标出的缺项。风格可以选择预设、自由设计，或上传参考图片和视频。
2. **确认讲稿。** 初稿生成后，会独立调用写作 Skill 调整表达，再展示给老师。可以直接编辑，也可以填写修改意见。预计超时会提示，由老师决定压缩或接受。
3. **查看分镜。** 选择「先看分镜」时，逐段查看画面、讲稿和动画说明。可以改画面文字或提出具体意见；选择「直接制作」则跳过此轮确认。
4. **等待制作。** 页面更新配音和渲染进度。时长需要重新确认时会出现弹窗。
5. **下载。** 成片、字幕和可编辑工程在交付页提供。

制作遇到网络问题时会自动重试。仍未恢复时，点击「从断点重试」；完成的阶段和片段按原课程复用。暂停后使用页面中的继续入口。

「流程与测试」打开 Dify 原生编辑器。这里可以查看节点、修改工作流和测试草稿；修改后需要再次发布，老师使用页才会更新。

`.runtime/teacher-flow/courses/` 保存课程状态、讲稿、分镜、音频和制作工程。
