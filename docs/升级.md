# 从 v0.1.x 升级

先暂停制作，备份 `.env`、`models.json`、`.runtime/` 和 Dify 数据。保留自己修改过的节点与提示词。

```sh
git pull --ff-only
bash scripts/install.sh
.venv/bin/python scripts/dify.py prepare
.venv/bin/python scripts/dify.py build
.venv/bin/python scripts/dify.py up
```

安装会保留已有 `.env` 和 `models.json`，补装 DeepSeek Harness。参照新版 `.env.example` 增加 Qwen、Gemini 和音色字段。之后重启本地制作服务。

在 Dify 导入新生成的 `teacher-video-economy.local.yml`、`teacher-video-quality.local.yml`，分别发布。旧应用与原课程保留，进行中的课程从原入口继续；新课程选择新方案入口。

已有 `models.json` 不会因升级自动改成省钱方案。需要切换默认分工时，运行：

```sh
.venv/bin/python scripts/local.py init --preset economy
```

质量优先使用 `--preset quality`，并安装 `requirements-adapter.txt`。这会改写本地默认角色文件；已导入应用的角色仍在各自的 `COURSE_MODELS` 中管理。

新增风格与旧三种共用同一流程。旧版课程没有声音配置字段时，继续按原来的 `qwen-audio-3.0-tts-plus`／`longanlingxin` 使用缓存；新课保存独立的声音设置。
