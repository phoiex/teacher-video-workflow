# 安装

需要 macOS Apple Silicon、Docker Desktop、Git、Python 3.12+、Node.js 22+、FFmpeg。Docker 建议分配至少 4 核和 8 GB 内存；首次构建会下载源码、镜像和浏览器。

## 1. 本地制作工具

```sh
git clone https://github.com/phoiex/teacher-video-workflow.git
cd teacher-video-workflow
bash scripts/install.sh
```

如果默认 Python 版本较旧，可以指定解释器：

```sh
TEACHER_PYTHON=python3.12 bash scripts/install.sh
```

在生成的 `.env` 中填写：

- `DEEPSEEK_API_KEY`：模型 API 密钥。
- `DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID`：百炼北京地域的语音服务凭据。

`models.json` 决定规划、写稿、改写和制作各用哪个模型。先保留默认配置即可。

## 2. Dify

```sh
.venv/bin/python scripts/dify.py prepare
.venv/bin/python scripts/dify.py build
.venv/bin/python scripts/dify.py up
```

脚本下载固定版本的 Dify，加入本仓库的改动，生成独立的本地口令。Dify 源码和数据放在 `vendor/dify/`。制作工具、课程和缓存放在 `.runtime/`。

打开 <http://127.0.0.1:8788>，创建本地管理员账户。

## 3. 启动与导入

另开一个终端，在仓库目录执行：

```sh
.venv/bin/python scripts/local.py doctor
.venv/bin/python scripts/local.py serve
```

保持这个终端运行。在 Dify 工作室选择「导入 DSL 文件」，导入 `.runtime/teacher-video.local.yml`。这个本地文件带有本次安装的工具口令，不要转发；分享流程时使用仓库的 `workflow/teacher-video.yml`。

导入后点击右上角「发布」→「运行应用」。老师从发布页提交课程要求；流程编辑器保留节点设置、测试和运行记录。

端口：Dify 为 `8788`，制作工具为 `8794`，可选协议适配为 `8795`。这些端口需要空闲，浏览器请使用 `127.0.0.1` 地址。

## 再次启动与停止

再次启动时执行 `scripts/dify.py up` 和 `scripts/local.py serve`。Dify 中的应用与课程会保留。

先在课程页面暂停制作，再在制作工具终端按 `Ctrl+C`，然后执行：

```sh
.venv/bin/python scripts/dify.py down
```

停止命令保留数据。备份包括 `.runtime/`、`vendor/dify/docker/volumes/` 和个人配置文件；备份中可能有密钥和课程材料，按本地私有文件保存。
