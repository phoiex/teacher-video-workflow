# 安装

需要 macOS Apple Silicon、Docker Desktop、Git、Python 3.12+、Node.js 22+ 和 FFmpeg。首次构建会下载 Dify 源码、镜像、制作运行时和 Chromium。Dify 建议分配至少 4 核、8 GB 内存。

## 本地制作工具

```sh
git clone https://github.com/phoiex/teacher-video-workflow.git
cd teacher-video-workflow
bash scripts/install.sh
```

Python 版本较旧时可用 `TEACHER_PYTHON=python3.12 bash scripts/install.sh`。安装脚本同时准备 Codex SDK、固定版本 DeepSeek Harness 和浏览器渲染器，不调用模型。

在 `.env` 中按[服务与音色配置](服务与音色.md)填写凭据。默认省钱方案需要 `DEEPSEEK_API_KEY`、`DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID`；Qwen 可复用百炼 Key，也可单独填写 `QWEN_API_KEY`。

若使用质量优先方案，补充 OpenAI、Gemini、Claude API Key，并安装本机协议适配依赖：

```sh
.venv/bin/python -m pip install -r requirements-adapter.txt
.venv/bin/python scripts/local.py init --preset quality
```

省钱方案可用 `scripts/local.py init --preset economy` 选回。`--preset` 会更新本地 `models.json`，已有自定义模型分工请先保存。

## Dify

```sh
.venv/bin/python scripts/dify.py prepare
.venv/bin/python scripts/dify.py build
.venv/bin/python scripts/dify.py up
```

打开 <http://127.0.0.1:8788>，创建管理员账户。Dify 源码和数据放在 `vendor/dify/`，制作工具的课程与缓存放在 `.runtime/`。

## 启动与导入

另开一个终端，在仓库目录执行：

```sh
.venv/bin/python scripts/local.py doctor
.venv/bin/python scripts/local.py serve
```

保持终端运行。在 Dify 工作室选择「导入 DSL 文件」，按需要导入：

- `.runtime/teacher-video-economy.local.yml`：省钱方案。
- `.runtime/teacher-video-quality.local.yml`：质量优先方案。
- `.runtime/teacher-video.local.yml`：跟随本地 `models.json` 的自定义方案。

两套方案可以同时导入。每个应用点击「发布」→「运行应用」，获得各自的老师使用入口；「流程与测试」仍进入原生节点编辑器。

`.local.yml` 包含安装时生成的本机工具口令，只用于本地导入。公开分享使用 `workflow/` 中不含口令的模板。

端口：Dify `8788`，本地制作工具 `8794`，质量优先方案的协议适配 `8795`。安装脚本只配置 Dify 到本机制作工具的访问。

## 再次启动与停止

再次执行 `scripts/dify.py up` 和 `scripts/local.py serve`。暂停正在制作的课程后，可在工具终端按 `Ctrl+C`，再运行：

```sh
.venv/bin/python scripts/dify.py down
```

停止会保留数据。备份 `.runtime/`、`vendor/dify/docker/volumes/`、`.env` 与 `models.json`；其中包含课程资料和本地凭据。
