# 配置与扩展

## 两套方案共用的功能

`presets/economy.json` 与 `presets/quality.json` 只决定模型分工；两份工作流的节点和连接完全相同，均有 76 个节点。课件解析、风格、审核、渲染和恢复逻辑由同一套代码提供。

四个角色分别是 `planner`（课程与材料规划）、`writer`（讲稿初稿）、`editor`（独立表达改写）、`producer`（分镜和画面）。首轮写稿与带完整 `deslop-zh` 的改写分开调用，改写结果再交老师确认。

每个角色可以配置 `provider`、`model`、`protocol`；按模型需要配置 `reasoning_effort`、`enable_thinking`、`catalog_model` 和 `harness`。支持的服务商为 `deepseek`、`qwen`、`openai`、`gemini`、`anthropic`、`custom`，地址和 Key 见 `.env.example`。

```json
{
  "provider": "qwen",
  "model": "qwen3.8-max",
  "protocol": "chat.completions",
  "enable_thinking": true
}
```

可以将上面的对象放到 `writer` 或 `editor`。Qwen 的开关只传给 Qwen；DeepSeek 的 `max` 通过原生 Harness 传入。其他服务不继承 Qwen 参数。

在 `models.json` 修改本地默认值后，运行 `scripts/local.py init` 更新自定义导入文件。命名的两套模板保持各自配置。已导入的 Dify 应用在环境变量 `COURSE_MODELS` 中编辑四角色 JSON，再发布即可；既有课程保存原角色与发布版本。

## 制作与配音

省钱方案使用 DeepSeek Harness `0.1.5-rc.1`，安装脚本在本地运行目录准备它和 Node 24。制作工具接到原生 SDK 会话，暂停后恢复同一 session。当前固定版本的 SDK 恢复入口补丁只作用于本项目运行副本。

质量优先方案使用 Codex SDK `0.154.0`；Claude 的 Messages 协议由本机 LiteLLM 转换为 Responses。Claude API Key 由本地读取，不需要登录 Claude 桌面端。直接支持 Responses 的模型不经过转换。

两种执行框架都能读取固定讲稿、保存分镜 HTML、渲染、看图、修改和继续制作。模型可通过 `course_style_source` 读取所选风格的作者材料。页面实现 `window.film.frame(t)`，统一由 Chromium 和 FFmpeg 导出。

配音模型和音色由 `.env` 的 `TTS_MODEL`、`TTS_VOICE` 设置，具体候选见[服务与音色](服务与音色.md)。建课时保存声音配置，已有课程的音频继续按原设置复用。

## 修改讲法、风格和节点

- `teacher_flow/prompts.py`：课程需求、规划、写稿和独立改写的提示词。
- `teacher_flow/instructions/`：分镜任务与制作工具说明。
- `skills/deslop-zh/`：中文表达规则。
- `skills/explainer-video-production/branches/`：十种视觉分支。
- `assets/style/catalog.json`：风格名称、分支、参考图、作者代码和来源的对应关系。

新增风格时补充分支和材料，更新目录以及两份 DSL 中的风格选项。把目录与图片同步到 `dify-overlay/web/public/teacher-style/`，重新构建前端、发布流程。已有制作任务继续使用开工时保存的材料。

Dify 节点仍可编辑和新增。现有生成节点通过 HTTP 调用本地制作工具；需要 Dify 原生 LLM 节点时，可在编辑器中添加并连接相应的数据字段。

## Dify 与本地检查

`dify-base.json` 固定 Dify 1.17.1 的源码提交及改动清单。`dify-overlay/` 主要涉及审核弹窗、实时进度、风格预览和原发布版本的恢复，保留原生发布、编辑器和运行记录。

```sh
.venv/bin/python -m unittest discover -s teacher_flow -t . -p 'test_*.py'
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
node --test teacher_flow/test_production_panel.mjs teacher_flow/test_storyboard_panel.mjs
.venv/bin/python scripts/smoke_render.py
.venv/bin/python scripts/check_public.py
```

这些检查使用固定数据和本地模拟模型。安装 DeepSeek Harness 后，其原生会话测试也会执行。完整课程的费用与效果需要从发布页实际制作后评价。
