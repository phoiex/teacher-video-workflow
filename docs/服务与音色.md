# API 服务与配音

凭据填写在仓库根目录的 `.env`，不放进 DSL 或公开仓库。省钱方案的最小配置是 DeepSeek API Key、百炼 API Key 和百炼 Workspace ID。

| 服务 | 本地字段 | 开通与说明 |
|---|---|---|
| DeepSeek | `DEEPSEEK_API_KEY` | [开放平台](https://platform.deepseek.com/)，用于规划与制作；[思考参数](https://api-docs.deepseek.com/guides/thinking_mode/)使用 `max`。 |
| Qwen 文字模型 | `QWEN_API_KEY`，留空可复用 `DASHSCOPE_API_KEY` | [百炼](https://bailian.console.aliyun.com/)开通 `qwen3.8-max`；采用[北京地域的兼容接口](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)，开启思考并流式接收。 |
| 千问配音 | `DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID` | 百炼北京地域，开通 `qwen-audio-3.0-tts-plus`。目前使用 Workspace 专属 `SpeechSynthesizer` HTTP 接口。 |
| GPT | `OPENAI_API_KEY` | [OpenAI API](https://platform.openai.com/)，示例为 [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)，使用 Responses。 |
| Gemini | `GEMINI_API_KEY` | [Google AI Studio](https://aistudio.google.com/apikey) 创建 Key 并配置计费；示例为 [Gemini 4 Argon](https://ai.google.dev/gemini-api/docs/models)，通过 OpenAI 兼容接口写稿。 |
| Claude | `ANTHROPIC_API_KEY` | [Claude API](https://platform.claude.com/)，示例为 [Claude Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview)。制作时通过本机协议适配接入 Codex SDK。 |

质量优先方案需要后三项模型服务与百炼配音；省钱方案需要前两家服务。各平台 API 独立计费。模型名称和可用地域以账户实际开通结果为准；配置支持修改，不绑定第三方中转。

## 配音与可选音色

默认配置：

```dotenv
TTS_MODEL=qwen-audio-3.0-tts-plus
TTS_VOICE=longanlingxin
```

| 模型 | 音色 ID | 声音 |
|---|---|---|
| `qwen-audio-3.0-tts-plus` | `longanlingxin` | 龙安灵心，温暖女声，项目默认。 |
| `qwen-audio-3.0-tts-plus` | `longanlufeng` | 龙安鲁风，明亮男声。 |
| `qwen-audio-3.0-tts-flash` | `longanfengyue` | 龙安风悦，自然女声。 |
| `qwen-audio-3.0-tts-flash` | `longanxiaoxin` | 龙安小昕，活泼女声。 |

音色 ID 须与模型匹配；完整列表、试听和更多基础音色见[阿里云官方音色表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。默认组合有既有课程实测记录；其他音色是官方可选项，本次未逐一合成试听。

输出固定为 24 kHz 单声道 WAV，按实际音频时长编排字幕与动画。老师可在课程要求中指定普通话、语速、语气和停顿。模型与音色在建课时保存，修改 `.env` 并重启本地工具后只影响新课程。

千问文字生成与千问语音合成是不同模型和接口。账户能写稿不代表已经开通语音服务；配音失败时按界面的错误与重试入口处理。
