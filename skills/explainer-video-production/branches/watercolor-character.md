# 水彩角色动画

水彩色块、墨线轮廓和纸面纹理组成场景。用一个连续的角色承接问题，角色的视线、姿态和行动与正在解释的对象发生关系，推动故事或演示。

角色形状和颜色在镜头间保持一致。轻微轮廓变化提供手绘感，动作有准备、行动和停留；需要讲清数字或关系时，让角色把注意引向图形与标注。人物、道具和场景按课程设计。

原作者底座使用 p5.js 与 p5.brush，包含画笔、时间、姿态和场景示例。可提取其中适合本课的绘制方法，在现有自包含 HTML 的 `window.film.frame(t)` 中实现。噪声、笔触和动作使用可从时刻重建的状态。
