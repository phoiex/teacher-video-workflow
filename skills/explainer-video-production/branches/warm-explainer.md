# 分支一：暖色图解

用于用户选择温和、纸面或暖色科普时。当前具体参考为用户指定的 B 站[《稳稳地接住你》gpt6 Astra VS opus 5.5](https://www.bilibili.com/video/BV1uTpU6GEHw/)，作者忧郁水壶hu。按用户的暖色需求，主要提炼画面下半部标为 Opus 的版本；上半部高对比拼贴是另一种选择。这里是观察提炼与教学适配，不是作者原始 Prompt 或 Skill。

## 输入与制作步骤


输入为主题或定稿、受众、画幅/时长范围、可用配音及参考。已有完整讲稿时直接进入分镜；已有配音时使用真实时长，不重做上游。

| 步骤 | 具体工作 | 留下的产物 |
|---|---|---|
| 内容与对象 | 按段确定要解释的关系，选少量反复出现的文字、图形或角色 | 口述与主对象对应表 |
| 画面方案 | 建立米白/深色字/暖色强调的层次，安排标题、图形、辅助字和稳定字幕 | 视觉规则与代表性静帧 |
| 动作分镜 | 为关系选动作：出现、支撑、重排、聚合、拆分、状态变化；保留跨镜头对象身份 | 每段动作与观察结论 |
| 工程复用 | 使用已有二维/网页/Remotion工程；补必要组件，不重造字幕与导出 | 可编辑场景及共用组件 |
| 配音对齐 | 以真实音频确定停留、强调和转场；歌词MV节奏不能直接沿用到课程 | 音频回执、字幕和动作时间表 |
| 短段到全片 | 先看最能暴露难点的一段，再扩展全片，按具体问题局部修改 | 实际预览、成片与源文件 |

上表是本项目根据参考画面制定的制作流程。作者的真实操作步骤、原始Prompt和所用引擎未公开核实；不要把上表写成作者实录。共用检查和续渲染见[制作流程](../references/production.md)，本机配音见[环境参考](../references/local-production.md)。

## 视觉方向

参考画面以米白、纸面感背景为主，配黑色粗体中文和陶土橙强调。画面大部分空间留给少量文字、简洁图形和小像素角色；软明暗边缘增加层次。没有证据确定具体字体、材质或渲染参数，不凭观感编造它的 CSS 或引擎。

不是全片都用浅色：参考中也出现深蓝和近黑段落，用于改变情绪或空间感；仍保持角色与图形语言连贯。教学中是否切深色，取决于它有没有帮助区分状态，而非固定每隔几秒切换。

暖色不是把科技画面换成黄色：终端网格、连续扫描线、错误日志与故障抖动仍然会形成终端视觉。普通讲解优先使用清晰文字、简洁图解和有因果关系的动作。

## 画面和动作

**文字是画面里的对象。** 可以分组出现、重排、倾斜、落下、被支撑、拆开或被线条划去。每项动作对应表达的含义，避免只是整句飞入再飞出。主标题、关键词、辅助标注和完整字幕各有职责；教学中的全文字幕保持稳定，不全部复制 MV 的动态歌词。

**把抽象意思变成具体关系。** 这条参考里能看到支架/平衡图形、角色承接爱心、方块破碎、文本卡片被划去、定位标记和圆形扩散等动作。迁移到课程时重新选数学或概念对象：相等可用平衡、合并可用聚拢、约束可用边界、条件变化可用对象状态变化。先核对对应关系，再做动效；不能拿视觉隐喻代替证明。

**小角色提供连续性。** 同一个小角色出现在不同段落，并参与承接、定位等动作。微课可以换成自己的简洁角色或一个反复出现的几何对象；不要求复制参考中的品牌形象，也不要求每节课都有吉祥物。

**重复主题可以复用构图。** 参考在后段回到熟悉的角色、定位标记和承接动作，并用标签散布形成变化。课程可在回顾时复现先前图形，让观众看到已经建立的关系；不要让装饰标签抢走解题对象的注意力。

新对象出现后给观众辨认的时间，重要关系成立时短暂停留。保持对象身份，让观众看见变化前后是同一个东西。参考是约 45 秒的音乐短片，时间密度跟随歌曲；课程使用真实口述和观察时间重新排动作，不直接复制原节奏。缓动与弹性可按内容选择，本次没有从抽样帧反推出原动画曲线。

中文字体明确指定并验证字库。上游 Manrope 等拉丁字体名称不能代表中文已经适配；可按项目现有许可字库选中文黑体或宋体，保证字幕和小标注读得清。

语气自然、具体、成熟；配音与背景音的取舍跟随受众和内容。没有背景音乐也可以完成这种风格，音乐和音效不属于强制步骤。

## 借鉴范围

主参考来自上述 B 站视频的实际画面：本次查看公开可取的 360×640 版本，抽看全片概览、关键帧与三段连续抽样。不能据此认定细微纹理、原始字体或最终高清质量，也未核实作者宣称的“一次生成”。简介和可读评论没有提供原始 Prompt、Skill 或工程；作者其他动态的访问不完整。

另有独立的 [MotionCraft warm-paper 配置](https://github.com/ahmdd4vd/MotionCraft/blob/8f4871543399c1981c247b734d9a123e6a6feb7a/skills/motioncraft/styles/warm-paper/tokens.json)可作实现起点：背景 `#faf7f1`、主文字 `#221c16`、强调 `#c2552d`。这些是 MotionCraft 的数值，不是从目标视频取得的源码；没有证据表明视频用了 MotionCraft。固定版本中它与柔和科技共用部分动画参数，因此调色后仍需设计教学节奏。

## 可用于制作交接的风格说明

下面是本项目依据画面自行整理的说明，可随具体讲稿调整：

> 采用温暖、简洁的二维动态图解：米白纸面感底色、黑色粗体中文、少量陶土橙强调，保持留白和清楚的主次。让关键词和图形参与解释，用移动、重排、支撑、合并或状态变化表达正在讲的关系；动作与口述同步，关键关系成立时停下来让人看清。可用一个简洁角色或几何对象贯穿，具体形象自行设计。必要时切换深色段落，但保持同一套图形语言。全文字幕稳定可读，具体镜头和动作由制作者组织，时长服从讲解。
