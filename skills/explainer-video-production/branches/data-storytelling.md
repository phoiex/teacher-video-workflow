# 数据叙事

让图表本身承担讲解。坐标、数据点和标注随着问题逐步出现，观众能看到一个数如何进入图形、不同数如何形成关系，以及整体规律怎样显现。

按内容选择点图、折线、条形、分布或比例图。每次变化对应明确的数据操作，例如增加样本、比较两组、变换尺度、突出一个区间。颜色有固定含义，轴、单位与数值保持可读。

数据沿用课程已确认的来源；教学示意值在画面或讲稿已有说明中标明。注释与所指数据保持连接，镜头移动后仍能找到对应关系。

原作者的 Canvas 引擎包含纸面、铅笔、图形、数值配色、镜头及注释定位。可按需提取，在当前 `window.film.frame(t)` 中组织动作；讲解的节奏服从本课旁白。
