# 可选科技视觉配置

本文件只补充通用视觉选项。实际制作先选[ASCII／终端科技](../branches/ascii-terminal.md)或[OpenFilm／代码动画科技](../branches/openfilm-cinematic.md)，不要把两条路线简化成同一套配色。

需要柔和的深色科技外观时，可参考 MotionCraft `tech-neon-soft`：深靛底 `#0b0c16`、浅色文字 `#eef1ff`、薄荷绿 `#7cf0c8` 和浅紫 `#b69cff`。它是独立配置，不是前述两支视频使用过它的证据。[固定版本配置](https://github.com/ahmdd4vd/MotionCraft/blob/8f4871543399c1981c247b734d9a123e6a6feb7a/skills/motioncraft/styles/tech-neon-soft/tokens.json)

同类对象保持稳定颜色，主要关系用对比或亮度突出，辉光不覆盖字和细线。空间运动用于解释朝向、遮挡、距离或层次；比较数值和推导时稳定镜头。技术感可以来自黑白、琥珀或浅色画面，不强制使用蓝紫霓虹。

对于算法与数学，手工布局、虚构概率或示意曲线与真实运行结果分开标明；几何对象和坐标变换保持数学正确。原MV的虚构数据只承担叙事，不作为课程实证。
